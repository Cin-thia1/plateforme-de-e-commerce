# My WordPress Theme

## Description
This is a custom WordPress theme created to replicate the design and functionality of an existing website using HTML, CSS, and JavaScript. The theme maintains the same coherence in style and includes multiple page templates.

## Files and Directories
- **assets/**: Contains all the assets for the theme.
  - **css/**: Contains the main CSS styles.
    - `style.css`: Main stylesheet for the theme.
  - **js/**: Contains JavaScript files.
    - `script.js`: JavaScript functionality for interactive elements.
  
- **inc/**: Contains PHP files for theme functions.
  - `functions.php`: Defines theme functions, registers menus, and enqueues styles and scripts.

- **templates/**: Contains page templates.
  - `page-home.php`: Template for the home page.
  - `page-about.php`: Template for the about page.
  - `page-contact.php`: Template for the contact page.

- `header.php`: Contains the header section of the theme.
- `footer.php`: Contains the footer section of the theme.
- `index.php`: Main template file for the theme.
- `style.css`: Theme stylesheet with header comment for WordPress.

## Installation
1. Download the theme files.
2. Upload the `my-wordpress-theme` directory to the `/wp-content/themes/` directory of your WordPress installation.
3. Go to the WordPress admin panel, navigate to Appearance > Themes.
4. Activate the "My WordPress Theme".

## Usage
- The theme includes templates for the home, about, and contact pages.
- Customize the theme by modifying the CSS in `assets/css/style.css` and the JavaScript in `assets/js/script.js`.
- Use the WordPress Customizer to adjust theme settings and options.
