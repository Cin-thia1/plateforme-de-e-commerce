Récupération du mot de passe

Entrez votre e‑mail pour recevoir un code de vérification. Ensuite, saisissez le code et choisissez un nouveau mot de passe.

Remarque : cette démo gère le code côté client. Pour une implémentation réelle, il faut envoyer le code depuis votre serveur par e‑mail et vérifier côté serveur.
